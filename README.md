PicklesScript (named after my dog Mr. Pickles)
- 
This is a toy language I am using to learn with the goal being to make mistakes and learn from them. 

PicklesScript is a register-based VM that emits bytecode through a recursive descent compiler, with syntax similar to C# / Python. 

Syntax
-
```
# This is a comment
print(6 + 7);
print("Hello world");
```  

Goals
-
- Create an object-oriented programming language that needs to be optimized
- Write benchmarks
- Optimize the language and observe improvements
